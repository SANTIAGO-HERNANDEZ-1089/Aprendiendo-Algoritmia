# 🚀 Ejercicios de Algoritmia

Bienvenido a este repositorio de práctica y aprendizaje de programación.

## 📖 Descripción

Este repositorio contiene ejercicios de algoritmia y lógica de programación desarrollados en diferentes lenguajes con el objetivo de fortalecer habilidades de análisis, resolución de problemas y desarrollo de software.

## 🛠️ Tecnologías Utilizadas

- 🐍 Python
- ☕ Java
- 🟨 JavaScript

## 📂 Contenido

Aquí encontrarás ejercicios relacionados con:

- Variables y tipos de datos
- Operadores
- Estructuras condicionales
- Ciclos (for y while)
- Funciones y métodos
- Arreglos y listas
- Algoritmos básicos
- Resolución de problemas lógicos

## 🎯 Objetivo

Practicar los fundamentos de la programación mediante ejercicios que permitan desarrollar el pensamiento lógico y mejorar las habilidades de codificación.
